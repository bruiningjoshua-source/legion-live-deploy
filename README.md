# Legion Live Deploy

Legion Live Deploy is a complete livestreaming creator economy platform. It enables creators to livestream, podcast, participate in affiliate marketplaces, manage brand promotions, and run their entire business from a single modern stack. 

## Features
- Livestreaming with advanced engagement features
- Integrated podcast recording and publishing
- Affiliate marketplace for creators to earn revenue
- Tools for managing brand promotions and sponsorships
- Real-time chat, moderation, and analytics
- Secure payments and Stripe integration
- Multi-device support using cutting-edge web technologies

## Technology Stack
- React, Vite, and modern ES2022+ JavaScript
- Tailwind CSS and PostCSS
- Radix UI, Floating UI components for rich UX
- Supabase backend and real-time features
- Stripe payments and financial infrastructure
- Agora/Zego for streaming and communications

## Getting Started
1. Clone the repository: `git clone https://github.com/bruiningjoshua-source/legion-live-deploy.git`
2. Install dependencies: `npm install`
3. Start in development mode: `npm run dev`

For full production deployment or advanced setup, see the source comments and configuration files.

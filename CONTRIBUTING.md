# Contributing to Legion Live Deploy

Thank you for considering contributing to this livestreaming creator economy platform! To maintain code quality and project stability, please follow these guidelines:

## How to Contribute
1. **Fork** the repository.
2. **Clone** your fork and create a feature branch (`git checkout -b my-feature`).
3. **Install** dependencies: `npm install`
4. **Lint/Typecheck** before commit: `npm run lint` and `npm run typecheck`
5. Submit a **pull request** describing your changes and reference any relevant issues.
6. Ensure your PR passes all CI checks.

## Code Quality
- Follow the coding style enforced by ESLint and Prettier.
- Write clear, concise commit messages.
- Add/update documentation as needed.

## Reporting Issues
- Use GitHub issues for bugs, enhancements, or questions.
- Check for duplicates before creating a new issue.

## Code of Conduct
Be respectful, inclusive, and supportive. See our Code of Conduct for details (if available).
